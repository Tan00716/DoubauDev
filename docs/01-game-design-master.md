## 玩家幻想：烬堡领主

玩家是「烬堡领主」：一个王国土崩瓦解后，怀揣着王国最后余烬的流浪领主。每一次开局，玩家带着一副仅存的记忆之牌（初始卡组）抵达一片新领地，在废墟上重建城堡、重聚军团、抵御夜袭的「夜王庭」——直到最终围攻之夜击败领地的夜之王，让这片土地重新燃起炉火。

**为什么是这个身份而不是别的**：指挥官、战争领主等幻想强调「向外征服」，而本游戏的全部系统（建造、守城、卡牌沉淀、Meta 解锁）都指向「在废墟上重建家园并守住它」。烬堡领主同时解释了三件事：为什么每局从零开始（流浪者一无所有）、为什么卡组会成长（记忆/遗物的回收与重铸）、为什么失败后仍有收获（余烬不灭，Meta 解锁的是「找回的记忆」）。叙事与机制在同一个身份上闭环。

# 核心 Hook

## 一句话 Hook

<callout emoji="💡">
**你的城堡，就是你的卡组：白天把牌打成一座城，夜里这座城就是你的手牌。**
</callout>

## 三句话 Pitch

白天，你在无时间压力的阵地上把卡牌「落阵」为常驻的军团与工事，经营一座会呼吸的城堡；入夜，敌军从预演可见的多路进攻，你用另一层战术手牌调度军团、触发连锁、临场增援，守住炉火。每一次存活都会把经验沉淀为卡牌的 A/B 机制分支，每一片征服的领地都改变你的经济与卡池——所以每一局的城堡都不一样，每一种打法都值得再来一局。

## 独特卖点：为什么不是参考游戏的替代品

| 对比游戏 | 它的核心体验 | 烬堡的差异化（不复制它的部分） |
|-|-|-|
| Thronefall | 极简建造 + 夜间守城，白天决策夜间观赏 | 保留昼夜节奏，但夜里不是观赏：战术手牌层 + 班级指令让夜晚成为主动决策段；建造物与卡牌双向转化 |
| Kingdom Rush | 关卡制经典塔防，固定路径 + 塔位 | 塔是 Build 的一环而非全部；塔与军团、卡牌、地形联动，且占用工令容量、有维持费，不存在「满图铺塔」最优解 |
| They Are Billions | 高压 colony survival，一失万劫 | 单局 40 分钟而非 10 小时；失败是 Roguelite 循环的一环（收获记忆），且错误可被夜间手牌部分补救 |
| Slay the Spire | 回合卡牌构筑，牌即行动 | 卡牌落阵为常驻实体（军械册层），构筑深度发生在「阵地规划 × 手牌调度」两层，而非纯抽弃循环 |
| Balatro | 指数级爆炸的引擎感 | 爽感来源不同：不是数字爆炸，而是「城堡成型」的空间感与六维联动的系统咬合感；数值增幅有硬上限（见平衡章节） |
| Vampire Survivors | 全自动割草，玩家只走位 | 明确不做全自动：半自动军团 + 主动打牌 + 白天规划三层决策；单位升级是机制变化而非纯数值 |
| Legion TD / 军团 | 赛前布阵，战斗全自动结算 | 战斗中保留打牌与班级指令的干预权；布阵错误可以在夜间修正，而非看着输 |
| Against the Storm | 城建 Roguelite，长会话 | 取其「每次重来都有新目标」的循环感，压缩到 40 分钟一局；Meta 成长零数值，避免其后期数值碾压问题 |
| Backpack Battles | 空间排布即构筑 | 我们的「空间」是战场本身：建筑位置、军团站位、地形利用即构筑的一部分，且对手是动态的夜王庭而非镜像玩家 |

# 核心 Gameplay Loop（五层）

## Moment-to-Moment（每 10 秒–1 分钟）

夜间的玩家处于「观察—判断—出手」的 5–15 秒节奏中：扫视三路敌军构成（威胁预演条提前 20 秒可见）→ 判断哪一路需要干预 → 做出三选一动作：打一张战术牌（战意允许吗）、给某个班下指令（移动补位 / 撤退保员 / 集火关键敌）、或按住不动攒战意。白天的 moment 层则是 30–60 秒的微决策：这块地皮放箭塔还是市集、哪个班升 A 分支还是 B 分支、金币修墙还是存着买卡。

## Short Loop（每 2–5 分钟：一个昼夜循环）

1. 天亮结算：修复建筑、召回阵亡班（付费）、结算战勋、收取军饷维持费；
2. 白昼建设（60–120 秒，可跳过）：建造 / 升级 / 布阵 / 商店 / 移除卡；
3. 入夜预演（10 秒）：本轮进攻路线、敌人构成、特殊规则全部可见；
4. 夜间守城（3–6 分钟）：波次进攻 + 打牌 + 班级指令；
5. 夜末清算：城墙耐久、战意结余（上限 40，超出部分按 50% 折算为金币）、应急增援实体进入受损归营堆。

## Combat Loop（战斗内循环）

接敌产生战意 → 战意打出战术牌 / 应急增援 → 卡牌效果改变局部战局（控制 / 增益 / 补位）→ 军团与塔在半自动规则下收割 → 击杀掉落战意与少量金币 → 攒够关键牌费用打出终结连锁 → 波次间隙 15 秒（唯一可修墙 / 移位的夜间窗口）。这个循环的张力在于：战意只有接敌才产生（不能挂机攒），而手牌上限 5 张迫使玩家在「现在打」与「留给下一波」之间取舍。

## Run Loop（一局完整结构）

选择指挥官与初始遗令 → 抵达领地（初始 10 张卡 + 500 金）→ 昼夜循环 × 5–7（穿插领地扩张选择、精英领主夜、事件、市集、篝火）→ 终局围攻之夜（夜之王 Boss 战）→ 胜利结算（记忆碎片 + 图鉴进度）或失败结算（部分记忆碎片 + 死因分析）→ 回到 Meta 层重开一局。

## Meta Loop（局与局之间）

死亡 / 胜利后：结算记忆碎片 → 王国厅解锁树（新指挥官 / 新卡 / 新建筑蓝图 / 新敌人情报 / 规则型起始强化）→ 用新选项重开一局 → 用不同 Build 应对新解锁的敌人与法则 → 更高「荒土法则」难度层。Meta 层的铁律：解锁的全部是「新选项」而非「数值加成」，第 100 局的玩家与第 1 局的玩家在基础数值上完全平等，差距只在可选项数量与玩家自身的理解。

# 设计支柱（5 条）

| 支柱 | 解决什么问题 | 玩家感受 | 支撑系统 / 破坏条件 |
|-|-|-|-|
| **阵地即构筑** | 传统塔防的「塔位摆好后无事可做」与卡牌游戏的「构筑与战场割裂」 | 「我摆下的每个东西都是我的牌，我的牌都在场上活着」 | 落阵/归营机制、军械册、A/B 分支；破坏条件：出现纯数值塔升级或与阵地无关的强力卡 |
| **有保留的紧张** | 即时守城的压迫感与 Roguelite 容错需求的矛盾 | 「这一波很险，但我手里还有牌」 | 威胁预演、夜间手牌、休整召回；破坏条件：出现不可预见的即死机制或无解波次 |
| **双资源昼夜张力** | 单一经济导致的最优解固化 | 「白天精打细算，夜里慷慨赴死」 | 金币（昼/存量）与战意（夜/流量）双轨 + 军饷维持费；破坏条件：出现金币可买战意的直接兑换渠道 |
| **失败即情报** | Roguelite 挫败感与重开动力 | 「我知道哪里错了，下一局我要换个打法」 | 死因分析、敌人图鉴解锁、Build 收集图鉴；破坏条件：Meta 数值成长让「再来一局变强」替代「再来一局变会」 |
| **十秒可读** | 多系统叠加后的战场混乱 | 「再乱我也看得懂谁在打谁、谁快死了」 | 班级制的视觉聚合、轮廓色彩语言、特效预算制度；破坏条件：同屏特效或单位超过可读性预算 |

# 一局完整结构与阶段基准

一局 = 一片领地 + 一座主堡（烬堡本体，Wanderburg 式持续成长的核心）+ 6–8 个昼夜循环。征服的每个「扩张领地」直接改变主堡可用区域（新建筑槽）、资源产出与卡池倾向。下表为一局 8 昼夜版的标准基准（Normal 难度），数值为初始设计值，QA 阶段需用战斗模拟器校准：

| 阶段 | 昼夜 1–2（开局） | 昼夜 3–5（中期） | 昼夜 6–7（后期） | 昼夜 6 / 7（领主夜） | 昼夜 8（终局围攻） |
|-|-|-|-|-|-|
| 时长 | 每夜 2–3 分钟 | 每夜 3–5 分钟 | 每夜 4–6 分钟 | 5–7 分钟 | 6–8 分钟（三阶段） |
| 金币规模 | 存量 150–300 | 500–800 | 900–1400 | 同左 | 终局战前 1500 左右 |
| 军团规模 | 2–3 班 | 5–6 班 | 8–10 班 | 7–10 班 | 10–12 班（满编） |
| 建筑数量 | 3–5 座 | 8–11 座 | 13–16 座 | 同左 | 16–18 座 |
| 卡组（军械册/战术） | 6 / 4 张 | 12 / 8 张 | 18 / 12 张 | 同左 | 20 / 14 张（软上限） |
| 敌军构成 | 2 种基础敌，1–2 路 | +2 新类型，2–3 路 | +2 新类型与首个性组合，3–4 路 | 精英领主 + 专属护卫 | 夜之王 + 全类型混编 |
| 难度变化 | 分阶段教学：第 1 波只教班级指令，第 2 波教战意和打牌，第 3 波整合；首夜城墙耐久 +50% 失败保护 | 威胁预演开始出现「未知敌」（图鉴解锁前） | 诅咒开始生效；资源竞争加剧 | 规则级挑战（见 Boss 章节） | 三阶段，每阶段改变一次战场规则 |

# 军团系统

## 军团结构：班（Squad）为最小指挥单位

军团结构从上到下：**军团（玩家全部兵力）→ 班（Squad，最小指挥与卡牌单位，3–8 个视觉单位）→ 视觉单位（纯表现层，玩家不直接操作）**。阵型（方阵 / 横列 / 楔形）与站位（前中后排）在白天布阵阶段设定，夜间可整体切换但消耗一次打牌机会。玩家永远指挥「班」而非「兵」——这是操控深度与可读性的分界线。

## 单位角色（8 种，每种存在的理由都来自 Core Loop）

| 单位 | 角色 / 定位 | 强度 | 弱点与被克制 | 攻击 / 防御类型 | 机动与技能 | 升级路径（A/B 分支示例）与推荐 Build |
|-|-|-|-|-|-|-|
| 盾卫 | 线列坦克，扛住第一波接触 | 对物理前排极硬，持盾格挡远程 | 怕绕后与攻城溅射 | 近战 / 高护甲格挡 | 慢；「盾墙」原地格挡翻倍 | A 铁壁（嘲讽光环）/ B 盾冲（击退开团）；龟城、巨兽近卫 |
| 枪卒 | 反冲锋线控，廉价前排 | 对冲锋类伤害 ×2 | 近身后脆弱 | 长柄近战 / 中甲 | 慢；「拒马」驻守时对骑兵反伤 | A 长墙（驻守范围+1）/ B 破骑（反伤翻倍）；龟城、箭雨 |
| 弓手 | 主力远程输出 | 高处射程 +2，持续输出最高 | 被近身即溃散 | 远程物理 / 无甲 | 中；「齐射」手动集火技能 | A 长弓（射程）/ B 火箭（点燃地形）；箭雨领域、燎原 |
| 游骑 | 机动骚扰、抢经济、切后排 | 对远程与攻城敌极强 | 正面撞枪卒即死 | 近战冲锋 / 轻甲闪避 | 极快；「劫掠」击杀掉金币 | A 猎杀（对孤立敌+100%）/ B 疾风（脱战加速）；游骑劫掠、战争经济 |
| 工匠 | 工程核心：修墙、布雷、启用废墟 | 唯一能夜间修墙的单位 | 无战斗力 | 无攻击 / 无甲 | 慢；「抢修」恢复建筑 30% 耐久 | A 布雷（每夜 3 个陷阱）/ B 启用（激活地图废墟建筑）；龟城、工事大师 |
| 医师 | 治疗与召回，消耗战核心 | 持续恢复 + 阵亡单位减召回费 | 被集火优先阵亡 | 无攻击 / 无甲 | 慢；「急救」对单班瞬回 | A 战地医院（召回免费）/ B 群疗（范围治疗）；巨兽近卫、亡者归还 |
| 咒术师 | 范围法术，破集群 | 对 5+ 密集敌群伤害质变 | 怕单体刺客贴脸 | 范围法术 / 无甲 | 慢；「余烬风暴」大范围 DoT | A 燎原（点燃地形）/ B 陨落（单点爆发）；燎原、霜锁（B' 冰系变体卡） |
| 巨兽 | 精英重装，一个班即一支军队 | 对建筑类敌人极强，踩踏群伤 | 占 3 军令，怕屠戟卫 | 近战溅射 / 重甲 | 慢；「震地」范围眩晕 | A 攻城巨兽（对墙敌+200%）/ B 守护巨兽（为周围班承伤）；巨兽近卫 |
| 亡灵班 | 召唤物军团，消耗战弹性兵力 | 半价招募，夜末消散，阵亡不产士气惩罚 | 怕净化类敌人、疫病领主毒尸 | 近战 / 无甲 | 中；与莫尔甘指挥官联动：阵亡返还 50% 召唤费用（战意形式），「征魂」复活 | 无 A/B 分支；数量由卡牌与建筑叠加 |

克制关系全部遵循视觉直觉（枪长克骑、盾挡箭、火克密集、近身克弓），不要求玩家记忆克制表。召唤物（亡灵、哨兵傀儡）不属于班系统，由卡牌与建筑产生、夜末消散，用于蜂群类 Build 的弹性兵力。

# 军团规模决策（唯一推荐）

## 四档规模全维度分析

| 维度 | 10 班（≈30 兵） | 20 班（≈80 兵） | 50 班（≈200 兵） | 100+ 班（400+ 兵） |
|-|-|-|-|-|
| 玩法可读性 | 极高，每个班都认得出 | 高，但夜战中开始顾不过来 | 低，班沦为背景板 | 不可读 |
| 玩家控制感 | 每班指令都有意义 | 只能管重点班 | 退化成自动战斗 | 无控制可言 |
| AI / 寻路复杂度 | 低，班级行为即可 | 中，需要分组寻路 | 高，拥堵与死锁频发 | 极高，独立游戏团队不可承受 |
| CPU / GPU / 动画 | 预算充裕，可给单兵精致动画 | 需 LOD 与合批 | 需 GPU instancing + 行为降级 | 渲染与逻辑双瓶颈 |
| 与卡牌层的兼容 | 打牌节奏不被冲淡 | 勉强兼容 | 卡牌层被淹没，退化为 Legion TD | 卡牌层完全失效 |
| 战略感来源 | 靠组合与位置，不靠数量 | 数量感开始出现 | 纯数量感，与「落阵/归营」机制冲突 | 只有数量感 |

## 结论：指挥 10–12 个班，同屏视觉单位 ≤80（友方）/ ≤150（敌方）

**唯一推荐规模：玩家指挥上限 12 个班（军令容量 12–18 点，班均 1–3 点），单班 3–8 个视觉单位，友方同屏峰值 ≤80 个渲染单位，敌方同屏峰值 ≤150。**理由：本游戏的核心 Hook 是「城堡即卡组」，任何让卡牌层被单位数量淹没的规模都会杀死核心体验；10–12 班让「每一个班都是一张牌、一次决策、一段沉没成本」，与军械册机制严丝合缝。规模感通过「班的人数增长、体型差异、旗帜与升级光效」表达，而非堆数量——巨兽班 1 个单位占 3 军令，本身就是「少而重」的表达。100+ 档彻底排除；50 档仅在终局围攻的敌方波次中作为视觉奇观出现（敌人无 AI 复杂度问题，走群体寻路降级）。

# 塔防系统：塔是 Build 部件，不是数值桩

## 设计原则

传统 Arrow Tower → Level 2 → Level 3 式纯数值升级**全部废除**。塔的升级是 A/B 机制分支（二选一、不可逆），塔的价值来自与其他五维的联动。塔防只是本游戏的「三分之一」而非主体：塔、军团、卡牌三者共享工令/军令容量与金币/战意两货币，任何单押塔的打法都会被针对性敌人惩罚（破塔者、投石巨兽）。

# 卡牌系统：两层牌库

## 牌库分层（本设计的关键结构决策）

<callout emoji="💡">
军械册（Armory，落阵层）：单位卡与建筑卡。白天打出后常驻战场，不参与抽弃循环；同名牌再次打出 = 对该实体执行升级（走 A/B 分支或规模 +50%，机制变化优先）。实体被摧毁后对应卡进入「归营堆」，休整时可付费召回（半血入场）。夜间以 1.5 倍战意应急打出的单位卡（应急增援）夜末进入「受损归营堆」，次日白天可花 50% 金币修复（半血入场）。
**战术手牌（Tactic，循环层）**：战术卡、阵型卡、遗令卡。正常抽弃循环：夜间每 8 秒抽 1 张，手牌上限 5，波次间隙弃 2 抽 2。
</callout>

这个双层结构解决了纯 deckbuilder 与即时守城融合时最大的病灶——「抽到重复单位卡」与「核心战力依赖抽牌运气」：你的常驻战力（军械册）已经在场上，抽牌层只负责临场调度，运气差影响的是这一夜的流畅度，不是你的存在本身。

## 卡牌类别（5 类）与设计字段

| 类别 | 循环层 | 定义与费用 | 示例与反制（Counterplay） |
|-|-|-|-|
| 单位卡 | 军械册 | 白天金币落阵 / 夜间战意 1.5 倍应急增援 | 「游骑班」：落地即接敌（夜间打出附带 3 秒加速）；反制：敌方屠戟卫范围斩击 |
| 建筑卡 | 军械册 | 白天金币落阵；夜间不可打出（工程卡除外） | 「轰炮台」；反制：投石巨兽超射程拆塔 |

统一字段规范（每张卡必须填满才能进卡池）：Cost（昼/夜双价）/ Effect / Target / Duration / Rarity（普通·稀有·史诗·传说）/ Upgrade（A/B 分支）/ Synergy（至少与另外两维有明确联动）/ Counterplay（至少一种敌人或敌人组合能惩罚它）。初始卡池 60 张（普通 24 / 稀有 20 / 史诗 12 / 传说 4），全量池 200 张（分批随 Meta 与更新解锁）。

# 卡组构筑规则与三个必须回答的问题

## 构筑规则

- **初始卡组**：10 张 = 指挥官专属 2 张 + 军械册基础 6 张 + 战术基础 2 张；
- **获取**：每夜胜利 3 选 1（按当前 Build 缺口加权，见下）；领地宝箱、市集商店（40–120 金/张，可议价事件）、事件奖励、Boss 掉落（必出史诗以上）；
- **升级**：战勋解锁 A/B 分支（不可逆）；篝火可「重铸」——把一张已选分支回退（一局 1 次）；
- **移除**：篝火可撕 1 张战术卡（免费 1 次，之后 80 金/张）；军械册卡不可撕只能卖实体（返还 50%）；
- **复制**：市集「誊抄」服务（120 金，限战术卡）；军械册同名牌即升级，无复制需求；
- **传说卡**：4 张，均改写一条规则（例：「筑堡令」——城墙与塔获得 25% 生命偷取），全部来自隐藏事件与终极 Boss。

## 为什么玩家不会只用一套固定卡组

1. **奖励加权**：3 选 1 的池子按「当前卡组缺失的联动环」加权出现（你已有弓手 ×3，则箭雨类与保护类权重上升），抄来的「最优卡组」在中途就会被系统带偏成你自己的版本；
2. **环境轮换**：每片领地的敌人构成、领主与最终 Boss 从 9 类敌 / 9 个 Boss 中按领地种子抽取并**提前可见**——卡组是针对环境的答案，环境变了答案就变；
3. **分支不可逆**：A/B 升级与遗令互斥让同一条思路也有至少 4 种终态；
4. **指挥官规则差异**：卡恩禁远程塔、薇拉塔伤害 -20%——同一张卡在四个指挥官手里的价值排序完全不同。

## 为什么坏运气不会直接判负

1. **常驻战力在场**：军械册实体不依赖抽牌，最差的一夜也只是「打得笨」，不是「没有兵」；
2. **保底抽牌**：每夜第一抽必为「未拥有卡」，第三波起手必有一张 ≤5 费战术卡；
3. **确定性修复渠道**：市集商店明码标价、篝火移除/重铸、领地宝箱保底稀有——烂卡流可以通过「卖卡 + 买实体」转型纯阵地流（薇拉 / 龟城路线天然不依赖手牌质量）；
4. 绝境战意：主堡炉火耐久低于 30% 且当夜已接敌的班战意产出 +50%——濒死局面反而有更高的干预资源，翻盘窗口始终存在，但卖血刷战意不可行。

## 为什么卡牌选择产生真正的战略差异

因为每张卡同时改变三个层面：场上的空间格局（落阵位置）、后续卡池的加权方向（构筑轨道）、以及资源的时间分配（昼金 vs 夜战意）。选「火油桶」还是「霜冻箭」不是选伤害数字，是选「我要把这片领地打成一片火海，还是一座冰牢」——前者与咒术师 / 箭塔 B 分支咬合，后者与霜塔 / 尖刺陷阱咬合，后续十张卡的选择都会被这个决定塑形。

# 六维联动矩阵（Card × Army × Building × Commander × Economy × Terrain）

## 示范联动链（完整闭环）

1. 卡牌层：玩家打出战术卡「猎风祝福」——弓手班攻击附加 20% 减速；
2. 军团层：弓手班已升 B 分支「火箭」——攻击点燃地形；减速让敌人在火里停留更久（卡 × 军团）；
3. 建筑层：弓手站位在箭塔 B 分支「箭雨塔」与军械塔旁——军械塔让弓手攻击附带弃牌堆最后一张卡的 30% 效果，等于卡牌效果二次施放（军团 × 建筑 × 卡牌）；
4. 指挥官层：奥恩的「诗行」让第三张火系战术卡费用 -1——玩家把整个手牌循环往火系倾斜（卡 × 指挥官）；
5. 经济层：税塔把击杀转化为金币、战意结余折半转金——火力越猛，明天能买越多（经济闭合）；
6. 地形层：这一切被放在「高地 + 窄桥」的咽喉地形上——射程 +2、敌人被迫排队过桥（地形放大全部五维）。

这条链是游戏的「标准深度样板」：12 个系统中没有任何一个需要新加数值，全部是既有机制的乘法。

# 天赋系统（局内战旗 / Meta 王国厅）

## 局内：战旗（每攻克一个领地 3 选 1，一局 4–6 次）

战旗优先提供新机制而非数值。示例池（12 条，全池 30 条）：

- 「夜间回收」：可将一个班撤回军械册并返还全部军令（换兵自由）；
- 「余烬经济」：弃牌堆每有 5 张战术卡，天亮 +10 金；
- 「纵深防御」：城墙被突破后，主堡周围出现自动民兵（一局 2 次）；
- 「战争践踏」：巨兽类单位可摧毁敌方尸体，阻止疫医利用；
- 「紧急征召」：手牌为空时，自动免费抽 1 张基础枪卒卡；
- 「火线提拔」：本夜存活的所有班战勋 ×2；
- 「地形学家」：所有地形卡费用 -2；
- 「重装行军」：阵型切换不再消耗打牌机会；
- 「以战养战」：击杀建筑类敌人返还 4 战意；
- 「学者军团」：3 选 1 卡牌奖励改为 4 选 1；
- 「箭塔哨戒」：所有塔夜间自动攻击一格内掘地者（反隐）；
- 「最后通牒」：主堡耐久归零时，触发一次全场 15 秒无敌（一局 1 次）。

## Meta：王国厅解锁树（零数值铁律）

死亡 / 胜利结算「记忆碎片」，在王国厅消费。全部解锁项都是**新选项**：新指挥官（3 名）、新单位卡与建筑卡（进入加权池，初始 60 张 → 全池 200 张，需 20–40 局逐步解锁）、新建筑蓝图（诱饵塔、军械塔等进阶建筑初始锁定）、敌人图鉴条目（解锁「威胁预演」中的未知敌详情——情报即力量）、规则型起始强化（如「开局自选 1 张遗令」）。**王国厅中不存在任何 +5% 类数值节点**；玩家变强只因为「会了」和「多了选项」，第 100 局的数值基线与第 1 局完全一致。

# Roguelite 结构

| 要素 | 规则 | 设计意图 |
|-|-|-|
| 随机奖励 | 每夜胜利 3 选 1（缺口加权） | 定向随机：保留惊喜，抑制烂抽 |
| 路线选择 | 领地节点 2–3 选 1，威胁与奖励全可见 | 把「赌什么」前置成明牌决策 |
| 事件 | 30+ 事件，多为 2–3 选项的风险契约 | 例：「流民求收留」——收（+1 免费班，军饷 +10/夜）或拒（无事）或征作民夫（+200 金，士气诅咒） |
| 精英 | 昼夜 6/7 的领主夜，规则级挑战 | Boss 系统的「期中考试」 |
| 宝箱 | 领地固定 1 + 事件随机，保底稀有 | 确定性奖励节奏点 |
| 商店 | 市集 B 集市或地图市集节点；卡 / 誊抄 / 议价 | 烂手牌的逃生通道 |
| 篝火 | 一局 2–3 次：免费撕 1 张 / 重铸分支 / 治疗全军 | 构筑修正 + 回血节奏 |
| 诅咒 | 高风险领地与贪婪事件的代价，规则型减益 | 例：「锈蚀」——塔攻速 -15%；可在净化事件中移除 |
| 风险 / 收益 | 每个领地节点标注威胁等级（1–5）与奖励等级（1–5），高风险 = 稀有卡 + 蓝图 + 净化 | 「安全路线 vs 高风险抉择」是每张地图的核心张力 |
| 难度修正 | 荒土法则叠层（见难度章节） | 规则复杂度替代数值膨胀 |

# 地图节点系统

一局的领地地图：**12–16 个节点、3 条并行层、单向前进、不回头**。结构为「烬堡（起点）→ 三段扩张层 → 终局围攻」。第 1 层固定 2 个战斗节点教学；第 2 层起每层 4–5 个节点中按路线走 3–4 个：战斗 / 精英 / 事件 / 市集 / 宝箱 / 篝火按种子生成并保证每层至少 1 个篝火或市集。分支点上，玩家可以看见后续 2 层的节点类型与威胁 / 奖励等级（领地类型：矿区 / 森林 / 河谷 / 废墟——决定地形、资源加成、卡池倾向与敌人构成），不可见的只有节点内部的具体事件内容。**随机性作用于「内容」，不作用于「信息」**：地图大小固定、节点数固定、类型与威胁可见——决策权始终在玩家手里，这是本 Roguelite 与纯随机跑马灯的分界。

# 经济系统（3 种资源，深度来自转化与张力）

| 资源 | 来源（Source） | 去向（Sink） | 稀缺性 | 战略含义 |
|-|-|-|-|-|
| **金币** | 市集税入（40 金/座/夜）、税塔击杀、游骑劫掠、事件、初始 500 | 建造（20–150）、召回（30–80）、商店（40–120）、军饷维持费（班 5/夜、塔 8/夜） | 存量型：可囤积但军饷随规模上涨，囤钱=放弃规模 | 白天的规划货币；「扩张规模 vs 现金流」的持续张力 |

# 战斗系统与操控定案：半自动控制

## 定案：半自动（明确排除另外两档）

<callout emoji="🎯">
**定案：半自动控制。**军团按白天的布阵与阵型规则自动接战，玩家保留三类干预权：班级指令、打牌、指挥官技。明确排除：纯自动战斗（会退化为 Legion TD 观赏局，杀死「有保留的紧张」支柱）；高度即时操作（APM 门槛与「十秒可读」支柱冲突，且 12 班 × 单兵微操超出独立游戏 AI 预算）。**不骑墙、不保留三档开关。**
</callout>

## 战斗流程要素

- **波次（Wave）**：每夜 1–4 波，入夜前 20 秒「威胁预演」显示每波路线、敌人构成与数量条；
- **敌人生成与路径**：从地图边缘 2–4 个巢穴生成，沿地形寻路（会绕开强火力区，除非被嘲讽 / 诱饵重定向）——堵路塑形（城墙 / 陷阱）因此有效；
- **目标（Objective）**：守住主堡炉火（主堡耐久 = 失败条）；城墙与建筑可损失、可修复；班可阵亡可召回——只有主堡是「命」。

## 玩家操作权限表（全部操作清单）

| 操作 | 阶段 | 输入 | 规则 |
|-|-|-|-|
| 移动 / 撤退 / 驻守 / 集火 | 昼 + 夜 | 右键 / 快捷键 1–9 选班 | 以班为单位；撤退指令让班脱离接战（不再产战意，持续 5 秒） |
| 打牌 | 主要夜间 | 手牌 1–5 键 + 左键指目标 | 军械册卡夜间打出走应急增援（1.5 倍战意） |
| 阵型切换 | 夜间 | Q/E 循环 | 消耗一次打牌机会（战旗「重装行军」可免除） |
| 建造 / 升级 / 拆除 | 仅白天 | 建造轮盘 B | 夜间仅工匠「抢修」与工程卡可修墙，不可新建 |
| 指挥官终极技 | 夜间 | R | 每夜一次，时机是核心决策 |
| 时间流速 | 夜间 | 空格暂停（可发令）/ 1x-2x | 暂停下令不限次——决策游戏不做手速惩罚 |

**明确不做的操作**：单兵控制、编队多组热键、巡逻路线、建筑量产队列、施法预瞄。操控深度上限 = 12 个班的指令 + 5 张手牌 + 1 个大招，同屏并发决策不超过 3 个——「控制深度不能高到变成 RTS，也不能低到只剩看动画」由这个硬预算保证。

# 难度设计：荒土法则（规则修正，非数值膨胀）

难度 = 法则叠层数。Normal（0 层）→ 困难（+2）→ 专家（+4）→ 荒土（+6）→ 无尽围城（专家基础上无终止夜）。禁止「HP +100% / 伤害 +100%」式调参——每个法则都是规则修正：

- 「夜更长」：所有夜晚波次 +1；
- 「雾夜」：夜间远程射程 -2 格（随机一半地图）；
- 「荒年」：市集税入 -30%，商店涨价 50%；
- 「坚壁」：敌方出现 1 个建筑类敌（能拆你的墙）；
- 「精英化」：每波敌人含 1 个精英词缀（击退 / 再生 / 死亡爆炸）；
- 「贪婪税」：金币存量超 800 的部分每夜 -10%；
- 「墓志铭」：招魂师回复速度 ×2；
- 「谜雾行军」：威胁预演只显示敌人数量，不显示类型。

法则池 20 条，按难度层从池中抽取（可重roll一次）。数值层面只保留两条全局修正：困难起敌人伤害 +10%、专家起主堡耐久 -15%——其余全部交给规则。难度切换在选指挥官界面，开局后不可改。

# UX / UI 设计

## HUD（昼夜同构双态）

昼夜共用同一套 HUD 骨架，仅信息权重切换——玩家肌肉记忆只有一套。顶栏左起：**主堡炉火耐久条（HP）→ 金币 / 战意（昼显示金币高亮、夜显示战意高亮）→ 军令 / 工令容量条**。右上：昼为「今日目标 + 商店入口」，夜为**威胁预演条（各路敌人构成色块 + 到达倒计时）**。底栏：昼为建造轮盘（B 键展开），夜为 5 张手牌 + 指挥官技 R。选中的班显示：血条、状态图标（≤3 个）、指令确认；班耐久 <30% 时显示预计召回费。任何时刻屏幕上同时变化的数字不超过 7 个。

## Build UI（建造轮盘）

B 键展开轮盘：可建建筑按类别弧形排列，每项显示**成本 + 工令占用 + 一行用途**；悬停 0.5 秒展开联动提示（「放在窄桥处半价」）；**已激活的协同以金色连线实时画在地图上**（如霜塔 + 尖刺范围重叠区）——协同可见化让 Build 深度不用读文档。升级界面：A/B 分支并排对比卡片，各显示一句机制描述 + 一个图标差异，选后不可逆（有二次确认）。

## Build 图鉴 UI

# 美术方向

- **视角与渲染**：正交俯视角 + 2.5D 低多边形（low-poly）建模，手绘质感纹理；3 档缩放，最远档保留辨识度（单位简化为剪影 + 血条）。
- **昼夜双色调**：白昼暖橙金（余烬 / 麦田 / 暖石），入夜过渡 5 秒渐变为冷蓝紫 + 点状炉火光源；色调切换本身就是「阶段切换」的无需文字的提示。
- **敌我轮廓语言**：夜王庭敌人 = 尖角 / 不对称 / 冷白 + 红橙内光；玩家方 = 圆钝 / 对称 / 暖金。同屏任何单位 0.5 秒内可判敌我。
- **等级可读性**：班的升级以旗帜样式 + 光环颜色表达（1 级无光、2 级微光、A/B 分支不同旗形）；禁止用体型膨胀表达升级（与规模语言冲突）。
- **VFX 预算**：同屏特效预算 200 粒子 + 8 个大型效果位；超预算时按「威胁优先级」衰减旧特效。火场 / 冰面等地形状态用区域色调 + 边缘光而非粒子堆。
- **动画**：单位 8 帧基础动画 ×4 状态（待机 / 移动 / 攻击 / 死亡）；班级行为用旗帜与队形变化表达，单兵动画保持简单——动画预算花在 Boss 与建筑升级瞬间。
- **参考基调**：Thronefall 的极简几何 + Bad North 的色彩平面构成 + 火焰纹章的纹章旗帜语言（仅参考气质，不复刻素材）。

# 音频方向

- **音乐**：双轨动态混音——白昼为竖琴 / 风笛 / 节奏自由的民谣变奏（Wanderburg 式炉火感），入夜切入战鼓 + 低音铜管的固定节奏层，战斗烈度（接敌班数）实时控制鼓点密度。Boss 战使用主题变奏 + 规则触发音（如时砂回溯的倒带声效）。
- **关键 SFX**：入夜号角（全游戏最重要的声音，预告威胁预演展开）、炉火熄灭（失败音，必须令人心碎）、班阵亡的旗帜落地声、A/B 分支选择的锻造锤声、抽牌 / 打牌的纸与火星混合声。
- **单位声音语言**：每个班 2 种语音（接战 / 阵亡），音色按角色区分；敌人无语音，用群体声床（狼嚎 / 亡灵低语）控制混音密度。
- **AI 制作可行性**：音乐用生成式工具产出分轨（昼夜两轨 ×3 烈度层，共 12 分钟循环素材）+ 程序化混音；SFX 以合成器采样 + 变体处理为主，UI 音全部程序生成——小团队不依赖外包录音棚；语音若成本超限，可降级为非语言战吼（发布版建议）。

# 玩家体验目标（六句验收句）

# 附录：供技术架构与 Steam 定位线引用的关键假设

- **同屏实体预算**：友方 ≤80 渲染单位（12 班 ×3–8 兵）+ 召唤物 ≤40；敌方同屏峰值 ≤150（群体寻路降级为流场 / 挤压解算）；建筑 + 塔一局 ≤18 座；同屏特效预算 200 粒子 + 8 大型效果位。
- **渲染与视角**：建议 2.5D——正交相机 + 3D 低多边形（Unity / Godot 均可胜任；若团队 3D 管线薄弱，备选方案为高清 2D 骨骼动画，需重估班级行为表现力）。粒子与光照需求低于市场中位，无实时光追 / 大规模布料需求。
- **目标平台**：PC（Steam）首发，Windows 为主、同步验证 macOS / Steam Deck 兼容；键鼠 + 手柄；最低配置目标为核显笔记本可 60fps（1080p）。
- **帧同步与暂停**：单人即时制 + 全局暂停下令（空格），无联机同步需求；存档粒度 = 昼夜边界（夜中不存档）。
- **数据驱动**：卡牌 / 单位 / 建筑 / 敌人 / Boss / 法则全部表格化数据（JSON 或 ScriptableObject），策划与 AI 编码工作流可直接批量生成与校验——这是「AI 大量参与开发」可行性的核心前提。
- **内容量级（供估时线引用）**：单位 8 ×2 分支、建筑 9 ×2、塔 8 ×2、卡牌 200（首批 60）、敌人 9、Boss 9、法则 20、战旗 30、事件 30+、地图模板 8、指挥官 4。
