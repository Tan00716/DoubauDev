# 烬堡 EMBERHOLD — M1 垂直切片

一个可在线试玩的 Web 游戏原型，验证「白天建堡 + 夜里守城 + 双层牌库 + 半自动操控」核心骨架。

## 在线试玩

> 在线预览地址：https://miaoda.feishu.cn/app/app_17f6k92p44e

## 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 开发模式（带热重载）
npm run dev

# 3. 生产构建
npm run build

# 4. 运行战斗结算单元测试（Vitest）
npm test

# 5. 预览生产构建
npm run preview
```

## 技术栈

- **TypeScript 5.3+** — 严格模式，ES2022 目标
- **Vite 5+** — 构建工具与开发服务器
- **Vitest** — 战斗结算回归单测（固定 dt 断言，防帧率依赖回归）
- **Three.js r160+** — WebGL 2.5D 正交渲染
- **Zod** — 运行时数据校验
- **HTML/CSS DOM** — UI 层（非 Canvas UI）

## 项目结构

```
src/
  core/
    event-bus.ts      # EventBus 模块解耦
  content/
    data.ts           # Zod Schema + M1 数据（单位/建筑/敌人/指挥官/卡牌）
  gameplay/
    game-state.ts     # 游戏状态机（昼/夜/过渡/结算）+ 双层牌库 + 波次表
    combat.ts         # 夜间战斗循环：事件式固定伤害结算、接敌战意、波次状态机
    __tests__/
      combat.test.ts  # 战斗结算回归单测（B1/B2/B3/I3/I5/I6/I7 断言）
  renderer/
    scene.ts          # Three.js 场景：正交相机、实体网格管理、火圈资源池化
  ui/
    ui.ts             # DOM 覆盖层：菜单、HUD、牌库面板、归营堆修复、威胁预演
  main.ts             # 游戏入口：初始化 + requestAnimationFrame 主循环
```

## M1 已实现内容

### 核心循环
- ✅ 白天建造阶段：从军械册打出建筑/单位卡到战场，同名牌在场再次落阵即升级（Lv1→Lv3，每级规模 +50%）
- ✅ 夜晚战斗阶段：每夜固定 3 波进攻（显式波次表，波间 15 秒间隙 + 弃 2 抽 2，波前威胁预演），友方自动寻敌/攻击
- ✅ 夜末清算：结算金币/战意/伤亡，战意结余按 50% 折金；守住第 8 夜通关
- ✅ 双层牌库：军械册层（常驻）+ 战术手牌层（初始 5 张含紧急增援，入夜抽 3 张，夜间每 8 秒补 1 张，上限 5 张循环）

### 实体与数据
- 1 名指挥官：奥恩（被动：每夜首张战术牌免费；终极技：终章）
- 3 种单位班：盾卫班、弓手班、枪卒班（对冲锋型敌人有反冲锋加成）
- 3 种建筑：石墙、箭塔、兵营
- 3 种敌人：狼群、盾卫、掘地者（敌方伤害已按 M1 数值校准基准 ×0.6 落地：狼 4 / 盾卫 6 / 掘地者 5）

### 操控方式（半自动）
- 白天：点击卡牌 → 点击地图放置；选中班组 → 点击地图移动
- 夜晚：班级指令（驻守/撤退/集火）、打战术牌（战意消耗）、指挥官终极技
- 受损归营：班组/建筑被摧毁后对应卡进入归营堆，次日花 50% 金币一次性修复（**含再入场**），修复后点击卡牌免费落阵、半血入场，无二次收费
- 不支持纯自动或完全手动微操

### 资源系统
- 金币：白天建造/升级/修复消耗
- 战意：夜间接敌班每秒产出 0.5（撤退后 5 秒封锁），用于打战术牌/指挥官技（上限 40，超出 50% 折金）
- 容量池：军令 6（单位）/ 工令 8（建筑）双容量，对齐设计文档基准

### 性能现状（如实描述）
- 实体网格按需创建、移除时递归 dispose geometry/material，无 GPU 资源泄漏
- 火圈特效使用共享 geometry/material + 网格池复用，不逐帧分配
- **尚未实现**（留待 MVP 性能阶段）：InstancedMesh 批量渲染、对象池化的完整实体网格复用、空间分区加速寻敌；目标「同屏 ≤80 友方 + ≤150 敌方时 ≥30fps」尚未经过压测验证

## 已知限制

1. **无音效** — 仅预留占位触发日志（M1 明确排除）
2. **无新手引导** — M1 由开发者自测，无教程流程
3. **无跨局 Meta 存档** — M1 仅支持单局内重启
4. **无多领土、事件、战旗、诅咒** — 留到 MVP
5. **美术为极简几何体** — 纯色低多边形，无贴图
6. **路径寻路简化** — 直线趋近，非 A*
7. **无网络同步** — 纯单机本地运行
8. **单 chunk 构建** — 产物约 570KB（gzip 后约 145KB），代码分割留 MVP
9. **帮助弹窗为原生 alert** — 面板化留 MVP
