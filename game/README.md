# 烬堡 EMBERHOLD — M1 垂直切片

一个可在线试玩的 Web 游戏原型，验证「白天建堡 + 夜里守城 + 双层牌库 + 半自动操控」核心骨架。

## 在线试玩

> 在线预览地址：部署后将在此处更新

## 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 开发模式（带热重载）
npm run dev

# 3. 生产构建
npm run build

# 4. 预览生产构建
npm run preview
```

## 技术栈

- **TypeScript 5.5+** — 严格模式，ES2022 目标
- **Vite 5+** — 构建工具与开发服务器
- **Three.js r160+** — WebGL 2.5D 正交渲染
- **Zod** — 运行时数据校验
- **HTML/CSS DOM** — UI 层（非 Canvas UI）

## 项目结构

```
src/
  core/
    event-bus.ts      # EventBus 模块解耦
  content/
    data.ts           # Zod Schema + M1 数据（单位/建筑/敌人/指挥官/卡牌）
  gameplay/
    game-state.ts     # 游戏状态机（昼/夜/过渡/结算）+ 双层牌库
    combat.ts         # 夜间战斗循环：寻敌、攻击、效果、波次
  renderer/
    scene.ts          # Three.js 场景：正交相机、对象池、几何体渲染
  ui/
    ui.ts             # DOM 覆盖层：菜单、HUD、牌库面板、结算/结束画面
  main.ts             # 游戏入口：初始化 + requestAnimationFrame 主循环
```

## M1 已实现内容

### 核心循环
- ✅ 白天建造阶段：使用金币从军械册打出建筑/单位卡到战场
- ✅ 夜晚战斗阶段：敌人波次进攻，友方自动寻敌/攻击
- ✅ 夜末清算：结算金币/战意/伤亡，进入下一天
- ✅ 双层牌库：军械册层（常驻，打出后实体常驻）+ 战术手牌层（每夜抽 5 张，夜末弃掉循环）

### 实体与数据
- 1 名指挥官：奥恩（被动：首张战术牌免费；终极技：终章）
- 3 种单位班：盾卫班、弓手班、长矛班
- 3 种建筑/塔：石墙、箭塔、兵营
- 3 种敌人：野狼、碎盾者、掘地虫

### 操控方式（半自动）
- 白天：点击卡牌 → 点击地图放置
- 夜晚：班级指令（集结/坚守/突击/后撤）、打战术牌、放指挥官技
- 不支持纯自动或完全手动微操

### 资源系统
- 金币：白天建造消耗
- 战意：夜间接敌产生，用于打战术牌/放指挥官技（上限 40）
- 容量池：同时可部署单位/建筑上限（M1 简化版）

### 性能优化
- 对象池复用 Three.js 网格
- 距离裁剪与空间分区
- 目标：同屏 ≤80 友方 + ≤150 敌方时 ≥30fps

## 已知限制

1. **无音效** — 仅预留占位触发日志（M1 明确排除）
2. **无新手引导** — M1 由开发者自测，无教程流程
3. **无跨局 Meta 存档** — M1 仅支持单局内重启
4. **无多领土、事件、战旗、诅咒** — 留到 MVP
5. **美术为极简几何体** — 纯色低多边形，无贴图
6. **路径寻路简化** — 直线趋近 + 简单避障，非 A*
7. **无网络同步** — 纯单机本地运行
8. **容量池简化** — 军令/工令合并为统一部署上限
